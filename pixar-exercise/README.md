# PIXAR HTML/CSS Exercise

This project implements the PIXAR website structure as specified in the academic exercise.

## Features Implemented:

### Main Page (index.html)
- White background
- Title 'PIXAR - Exemple HTML i CSS' at the top left
- Horizontal menu aligned to the right with:
  - Home
  - Sobre
  - Trabocos
  - Imagines
- Three image boxes:
  - Imatge 1 → links to pagina1.html
  - Imatge 2 → links to pagina2.html
  - Imatge 3 → links to pagina3.html

### Detail Pages (pagina1.html, pagina2.html, pagina3.html)
- Each page shows the corresponding image as the main image
- Maintains the same structure as the main page
- Each image occupies one of the three image boxes

### CSS Styling (css/style.css)
- Basic reset for margin and padding
- Clean, modern font styling
- Responsive grid layout for the images
- Blue color scheme with hover effects
- Styled navigation menu
- Image boxes with borders and hover effects
- Linear gradient headers

## Technical Details

- Uses semantic HTML5 elements
- CSS Grid for responsive layout
- Font Awesome icons would be used for menu icons (if available)
- All images are programmatically generated blue placeholder images with text

## How to Run

1. Open index.html in any web browser
2. Click on any of the three images to navigate to the detail page
3. The detail pages show the same image in full size

## Requirements

- Modern web browser with JavaScript support
- HTML5 and CSS3 compatible
